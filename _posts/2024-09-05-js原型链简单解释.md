## js原型链简单解释
js中存在两类对象，一类为定义有constructor的类，也就是函数类，此类的最直接父类为Function类，也就是空函数，另一类为没有定义constructor的类，也就是对象类，直接父类为Object类，也就是空对象。对象类实际上也有constructor，此constructor来自Object，用于创建空对象。
### 子类生成方式
js不存在java类的实例化这种说法，与java类似的实例化都是子类。
生成子类有三种方式：

1. 直接定义

2. new

3. Object.create()

代码实例如下：

```
var o1 = {name: 'value'};
var o2 = new Object({name: 'value'});

var M = function() {this.name = 'o3'};
var o3 = new M();

var P = {name: 'o4'};
var o4 = Object.create(P)
var F = Object.create(M.prototype);

```
其实这三种也是生成原型链的方式。

### 原型链生成
对于第一种方式生成的子类：

- 如果是函数类，它天然存在一个prototype属性，此属性值为对象类，此类的constructor属性值为此函数本身。它也存在__proto__属性，此属性值为Function，也就是空函数对象。
- 如果时对象类，它只有__proto__属性，此属性值为Object，也就是空对象。

对于第二种方式生成的子类：

- 对于对象类，用“new Object”方式，相当于类拷贝，生成的子类是Object的子类，不是 “new Object(参数)” 其中参数值携带的类的子类。

- 对于函数类，子类为对象类，子类的__proto__属性值为“new func”中func函数类的prototype的值。

对于第三种方式生成的子类：

- 对于对象类，生成的子类为空对象类，相当于调用了Object的constructor函数生成的子类，此空类的__proto__属性值为“Object.create(p)"中p这个对象类。

- 对于函数类， 生成的子类为对象类，相当于调用了“Object.create(M.prototype)”其中M.prototype的constructor属性对应的构造函数生成的子类，此子类的__proto__属性值为M.prototype值。如果将M.prototype换成M，此时M没有直接的constructor属性，Object.create会使用Function的constructor生成空函数子类，此子类的__proto__值为M。

### Object类与Function类关系
Object类的__proto__值为空，constructor属性值为Object()函数类。此函数类的prototype属性值为Object类，此函数类的__proto__属性值为Function类。
Function类是对象类，只有__proto__属性，属性值为Object类。Function的constructor属性值为函数类，此类的__proto__和prototype属性值都是Function类。
