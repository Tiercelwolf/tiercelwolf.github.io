## 箭头函数的this值
### 箭头函数的this指针继承外围this指针，这个外围是指定义箭头函数的函数或对象外围。例如：
```
const obj1 = {
  a: () => {
      console.log(this)
  }
}
obj1.a() //打印window对象
```
这个箭头函数定义在对象内部，对象是全局对象，对象外围的this是window，所以这个打印的this为window。

```
const obj = {
  a: function() {
      console.log(this)
      t = () => { 
          console.log(this) 
      };
      t();
  }
}
obj.a() //打印obj对象
```
箭头函数定义在传统函数内部，传统函数的外围this是指obj对象，所以这里打印的this为obj对象。

对于出现多层嵌套的情况，特别是同类型嵌套，this取值为window对象。例如对象嵌套：

```
const obj = {
  a: function() { console.log(this) },
  b: {
    c: {
      d: () => {console.log(this)}
    }
}
}
obj.a()   //没有使用箭头函数打出的是obj
obj.b.c.d() //打印出window对象
```
例如函数嵌套：

```
const obj = {
  a: function() {
      console.log(this)
      s = function(){
        t = () => { 
          console.log(this) 
        };
        t();
      }
      s();
  }
}
obj.a() //第一个打印是obj对象，第二个打印是window对象
```
在前头函数在settimeout中使用时，this指针也符合上述说明。例如：

```
const obj = {
  a: function() {
      console.log(this)
      window.setTimeout(() => { 
          console.log(this) 
      }, 1000)
  }
}
obj.a() //打印的都是obj对象。
```
箭头函数在传统函数中定义，传统函数外围是obj，这时this值为obj对象。放在settimeout中不改变this值。如果settimeout参数中的回调函数是传统函数，其中的this为window对象。另外使用call/apply/bind调用箭头函数不能改变其中的this值。
